Diseñé y desarrollé este portafolio con el objetivo de crear una experiencia que reflejara tanto mi perfil técnico como mi background creativo.

En lugar de utilizar una plantilla prediseñada, construí una interfaz propia enfocada en:

- Diseño responsive
- Componentes reutilizables
- Navegación sencilla
- Presentación de proyectos mediante casos de estudio

## ✦ Proyectos destacados

### 01 — News Explorer

Aplicación web para buscar, guardar y gestionar noticias.

El proyecto utiliza React y una API externa para realizar búsquedas de noticias e incluye navegación, autenticación y gestión de artículos guardados.

**Tecnologías principales:** React, JavaScript, React Router, REST API, JWT, HTML5, CSS3 y Vite.

### 02 — Around the U.S.

Aplicación web interactiva que permite gestionar un perfil y compartir fotografías mediante tarjetas.

El proyecto incluye edición de perfil, creación y eliminación de tarjetas, likes, validación de formularios y autenticación de usuarios.

**Tecnologías principales:** React, JavaScript, HTML5, CSS3, REST API, Node.js, Express y MongoDB.

## ✦ Ejecutar el proyecto localmente

Clona el repositorio:

```bash
git clone URL-DE-TU-REPOSITORIO
```

Entra al proyecto:

```bash
cd portfolio-estephania-tripleten
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```
